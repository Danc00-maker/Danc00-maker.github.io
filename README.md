# La economía de la atención y la desinformación

Sitio estático (GitHub Pages) del trabajo práctico de Ciencia, Tecnología y Sociedad, Tema 3.
Integrantes: Casco Ariel, Casco Luis, Casco Daniel.

Incluye: simulador de feed con reacciones, etapas interactivas del recomendador, línea de tiempo del caso 2025, compromisos de diseño responsable, propuestas desplegables y un quiz.

## Publicar en GitHub Pages
1. Subí estos archivos a la raíz de un repositorio nuevo.
2. Settings, Pages, Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
3. El sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Sin dependencias: HTML, CSS y JavaScript puros.
