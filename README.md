## Publicar en GitHub Pages
1. Subí estos archivos a la raíz de un repositorio nuevo.
2. En el repositorio: Settings, Pages, Source: "Deploy from a branch", branch `main`, carpeta `/ (root)`.
3. Esperá un minuto. El sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

No requiere instalación ni dependencias: HTML, CSS y JavaScript puros.
